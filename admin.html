1. GitHub 연결

Fine-grained personal access token이 필요합니다. github.com/settings/personal-access-tokens/new 에서 이 저장소 하나만 선택하고, Repository permissions → Contents를 "Read and write"로 지정해서 발급하세요. 토큰은 이 브라우저에만 저장되며(세션 종료 시 삭제), 파일에는 절대 포함되지 않습니다.
